# K-EXAM AI Tutor

AI Tutor เป็นโหมดฝึกถาม–ตอบของ K-EXAM สำหรับข้อสอบกรมสรรพากร โดยทำงานแยกจากโหมดทำข้อสอบมาตรฐาน และต้องไม่ลดมาตรฐานของคลังข้อสอบหลัก

## หลักการเลือกคำถาม
- ใช้เฉพาะ Question ID ที่อยู่สถานะ Published ใน `question-publication-manifest.json`
- ไม่สร้างเฉลยใหม่จากโมเดลภายนอก และไม่แทนที่เฉลยที่ผ่าน QA ของคลังข้อสอบ
- หลีกเลี่ยงการถาม Question ID ที่ผู้ใช้เพิ่งทำไป เพื่อเพิ่มความหลากหลาย
- ให้น้ำหนักหมวดที่ผู้ใช้มีอัตราตอบถูกต่ำกว่าเมื่อมีข้อมูลเพียงพอ
- แบ่งความยากเป็น พื้นฐาน / ปานกลาง / ท้าทาย และมีโหมดปรับอัตโนมัติ
- การแบ่งระดับความยากคำนวณจากความซับซ้อนของโจทย์และตัวเลือก แล้วแบ่งตามสัดส่วนของคลัง Published ที่ใช้งานจริง

## โหมดปรับอัตโนมัติ
โหมดปรับอัตโนมัติพิจารณาคำตอบในรอบปัจจุบัน
- เมื่อผลงานดีต่อเนื่อง ระบบสามารถเพิ่มระดับ
- เมื่อตอบผิดติดกันหรืออัตราถูกลดลง ระบบสามารถลดระดับ
- การปรับระดับมีวัตถุประสงค์เพื่อการฝึก ไม่ใช่การประเมินความสามารถเชิงจิตวิทยาหรือการทำนายผลสอบ

## คะแนนและการประเมิน
- คะแนนรอบ AI Tutor แสดงเป็นคะแนนฝึก 0–100
- คะแนนคำนวณโดยให้น้ำหนักตามระดับความยาก
- แสดงจำนวนตอบถูก ความแม่นยำ และ Streak แยกจากคะแนน
- ผลลัพธ์ต้องมีข้อความชัดเจนว่า “คะแนนนี้เป็นการประเมินจากการฝึกใน AI Tutor ไม่ใช่การคาดการณ์คะแนนสอบจริง”
- เมื่อจบรอบ ระบบสรุปหมวดที่ตอบผิดมากเพื่อใช้ทบทวน

## ระบบรางวัล
รางวัลเป็นกลไกส่งเสริมการฝึก ไม่เกี่ยวข้องกับคะแนนสอบจริง
- XP สำหรับความก้าวหน้าและระดับผู้ใช้
- เหรียญสำหรับคำตอบถูกและโบนัส Streak
- ดาวจากผลการฝึกในแต่ละรอบ
- ตรารางวัล เช่น ก้าวแรก, ต่อเนื่อง 5, ต่อเนื่อง 10, เต็มร้อย, พิชิตข้อท้าทาย, ครบ 50 ข้อ และสะสม 500 XP

## การจัดเก็บข้อมูล
- ประวัติ AI Tutor บันทึกใน localStorage ของอุปกรณ์ผู้ใช้
- เก็บคะแนนล่าสุด สถิติสะสม หมวดที่ทำแล้ว ความแม่นยำ รางวัล และประวัติรอบ
- สถิติของแต่ละตำแหน่งแยกกันใน profile เดียว
- หากยังไม่มี backend กลาง การเปลี่ยนอุปกรณ์หรือการล้างข้อมูลเบราว์เซอร์อาจทำให้ข้อมูลรางวัลในเครื่องนั้นไม่อยู่ต่อ

## ความถูกต้องและความปลอดภัยของเนื้อหา
- AI Tutor ต้องไม่ดึงข้อ Draft, Reviewed, Verified ที่ยังไม่ Published หรือ Retired มาใช้งาน
- ต้องใช้คำตอบ คำอธิบาย และเหตุผลตัวเลือกจากคลังข้อสอบที่เผยแพร่แล้ว
- หาก Question ID ถูก Retired ในภายหลัง รอบใหม่ต้องไม่เลือกข้อนั้น
- ห้ามฝังคีย์ API หรือเรียกโมเดลภายนอกจาก browser โดยตรง
- หากเพิ่ม Generative AI ภายหลัง ต้องใช้ backend ที่เก็บ secret ฝั่ง server และคำตอบเกี่ยวกับกฎหมาย/ภาษีต้องยึด source-verified content เป็นฐาน

## Analytics
บันทึกเหตุการณ์ขั้นต่ำ
- `ai_tutor_open`
- `ai_tutor_answer`
- `ai_tutor_session_complete`

Analytics ใช้เพื่อปรับประสบการณ์และดูประสิทธิผลของระบบฝึก ไม่ควรใช้สร้างข้อสรุปว่าผู้ใช้จะสอบผ่านหรือไม่

ชุดปกติ สุ่ม ข้อที่เคยผิด หมวดอ่อน และหัวข้อย่อยอ่อน

หัวข้อย่อยที่ควรทบทวนรวม

รวมผลการส่งข้อสอบตามช่วงวันที่ที่เลือก เรียงจากร้อยละตอบถูกต่ำ

ข้อที่ตอบผิดบ่อย

ใช้สำหรับตรวจคุณภาพข้อสอบและวางแผนทบทวนเนื้อหา

คิวตรวจคุณภาพข้อสอบอัตโนมัติ

รวมสัญญาณจาก p, D, ตัวลวงที่ไม่ทำงาน และรายงานจากผู้ใช้ เพื่อจัดลำดับ Question ID ที่ควรตรวจ

สถิติคุณภาพรายข้อ

สรุปด้วย Question ID: p = สัดส่วนตอบถูก, D = อำนาจจำแนกจากคะแนนข้ออื่น, DE = ประสิทธิภาพตัวลวง โดยใช้คำตอบครั้งแรกต่อผู้ใช้เพื่อลดอคติจากการทำซ้ำ

รายงานปัญหาข้อสอบ

รายการที่ผู้ทำข้อสอบกดแจ้ง พร้อม Question ID และประเภทปัญหาเพื่อใช้ตรวจทานต้นฉบับ

สถานะฐานข้อมูลส่วนกลาง

หน้าแดชบอร์ดและระบบติดตามถูกติดตั้งแล้ว แต่ต้องเชื่อมฐานข้อมูลก่อนจึงจะรวมข้อมูลจากผู้ใช้ทุกคนได้

ระบบเก็บเหตุการณ์พร้อมใช้งาน

หน้าเว็บบันทึกเหตุการณ์สำคัญ เช่น การเปิดระบบ การเลือกตำแหน่ง การเริ่มทำข้อสอบ และการส่งคำตอบไว้ในเครื่อง และพร้อมส่งขึ้นฐานข้อมูลทันทีเมื่อเชื่อม Supabase

ออกแบบโดยไม่เก็บชื่อผู้ใช้

ใช้รหัสสุ่มแบบไม่ระบุตัวตน แยกผู้ใช้โดยไม่ต้องกรอกชื่อ เบอร์โทร หรืออีเมล เหมาะสำหรับการวิเคราะห์การใช้งานทั่วไปและลดการเก็บข้อมูลส่วนบุคคลที่ไม่จำเป็น
